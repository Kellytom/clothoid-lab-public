What is exact, what is not

Each span is now a clothoid segment: a straight run is κ = 0, a circle is κ = 1/R, and the petal's Euler span runs κ linearly from 0 to 1/625 over ten degrees. The original converted those to 45° cubics and rounded every node to the 3125 lattice; the residual above is that rounding, not a geometry difference.

Corners are explicit: the old chain permits a tangent jump between spans, and each segment here carries Segment.corner. Without that the foot would bend into the tail base and every later node would drift.

Not done yet: the terminal choice per stroke and the 12.5 mm parallels are taken from the old set, not decided here; and the centre seam where the half meets its mirror is a real contact that must be declared before the clearance report can be believed.
