# The 3125 clothoid grid

What the reverse-curve brief gets right, what does not survive arithmetic, and
the exact coordinate rule to render from. Generated by `scripts/grid_3125.py`;
the numbers below are that script's output, not hand arithmetic.

## The curve

Standard Euler spiral, clothoid parameter `A = 3125`, curvature linear in arc
length and zero at the inflection:

```
theta(s) = s^2 / (2 A^2)
x(u)     = A sqrt(pi) C(u)
y(u)     = A sqrt(pi) S(u)
u        = s / (A sqrt(pi))
theta    = pi u^2 / 2
```

`C` and `S` are the Fresnel integrals. The script gets them from the compiled
Clothoids engine and checks them against the known values at `u = 1`
(`C = 0.7798934`, `S = 0.4382591`).

This is the whole construction. There is no polynomial approximation and no
iterative solve needed: one clothoid, parameter `u` from negative to positive,
turns one way below the inflection and the other way above it.

## Odd symmetry, verified

The S-pair is one clothoid crossing zero curvature:

```json
{"anchor": {"x": 0, "y": 0, "angle": 0},
 "segments": [{"kappa0": -0.000567185232289765, "kd": 1.024e-7, "length": 11078}]}
```

With `A = 3125` and half-length `L = A sqrt(pi)` (the 90 degree hook), the
inflection sits at `s = L`, curvature there is exactly `0`, and the two halves
are point reflections of each other:

- position symmetry error: `1.7e-11 mm` over 101 sample pairs
- tangent error: `1.3e-15 rad`
- `kappa` at the inflection: `0.0`, chain is G2

So "negate both coordinates about the inflection" is correct. Negating only `Y`
is not; the second half is the first half rotated 180 degrees about the
inflection, not mirrored across an axis.

## What does not check out

- **`5257` is not prime.** `5257 = 7 * 751`, so the "prime maximum envelope"
  argument is void.
- **`D_max` is `5256.75`, not `5256.99`.** True ratio `1.6821588`; the cited
  `1.6822365` is off by 0.24 units at this scale.
- **`D_max` occurs at theta `131.63 deg`, not `132.45 deg`**, at `u = 1.20938`.
- **The hook's X is `4319.77`, not `3000`.** The cited `4955` is the *radial*
  distance from the inflection (`4955.10`, which matches to 0.1). Mixing radius
  with X is what makes the `3000` claim possible; both cannot be true.
- **The 5/4 point does not land at 74.3% or 1.2193.** A tangent slope of 5/4 is
  theta `51.34 deg`, `u = 0.75528`, radius `4036.04` = `76.78%` of the envelope.
  The origin of `1.2193` is not recoverable from the numbers given; the brief
  should say what ratio it means before it is used.
- **Exact integer snapping is impossible.** `x` and `y` are transcendental.
  Rounding to an integer leaves at most 0.5 unit of error; rounding to a
  multiple of 125 leaves up to 58 units (table below), which is visible at this
  scale. Snap to integers, not to 125.
- **A 3125 canvas cannot hold a curve with `A = 3125`.** The envelope is
  `5256.75`, so the drawing is 1.68 times the stated canvas.

## Sheets are suggestions, not limits

There is no canvas limit in the geometry. Without `--page` or `--frame` the
sheet is the drawing's bounding box plus margin, so adding a curve simply grows
the sheet. `A = 3125` is the module, the 125 grid is a snapping aid, and the
sheet is how much paper the SVG declares. Only a fixed sheet creates a bound:

| Fixed sheet | Behaviour |
|---|---|
| none | sheet follows the drawing; unbounded |
| `--page WxH` | true millimetres; refuses a page smaller than the drawing |
| `--frame WxH` | scales the drawing to fill the sheet; the drawing can be any size |

The earlier idea that `3125` had to be "the canvas" was a confusion between the
module and the sheet. `A = 3125` is fine for any sheet, or for none at all.

**Working sheet for now: 200 × 250 mm.** That makes the 25 divisions
`8 × 10 mm`, which is why 200 mm was chosen over 575 pt (202.85 mm): the step
stays a round metric number, and 200 mm still prints on Letter. In Inkscape, set
the grid to 8 mm with a major line every 5 steps (40 mm); the rulers stay in
millimetres.

## Sizing a sheet, when you want one

Measured, not assumed. One **half** (inflection to the 90 degree hook) is
`4319.77 x 2427.48` = `1.3823A x 0.7768A`. A full **S** (both halves, point
reflected) doubles both numbers.

| Footprint | Width | Height | In `A` |
|---|---|---|---|
| one half, to 90 deg | 4319.77 | 2427.48 | 1.3823 x 0.7768 |
| one half, to the envelope | 4319.77 | 3492.40 | 1.3823 x 1.1176 |
| one full S, 90 deg halves | 8639.53 | 4854.96 | 2.7647 x 1.5536 |
| one full S, envelope halves | 8639.53 | 6984.79 | 2.7646 x 2.2351 |

So `2A = 6250` does **not** hold one full S: it is 2.76A wide. And `6A` is not
three curves — it holds `2.17` full S across, or `4.34` halves. These are facts
about the shape, not limits on the sheet.

A suggested starting sheet, with room for the pen and a 125 grid:

```
cell       3A x 2A      =  9375 x 6250   (75 x 50 steps of 125)
gap        625          =  A/5           (5 steps)
3 across   3*9375 + 4*625 = 30625 x 7500  (245 x 60 steps of 125)
```

If a smaller sheet is wanted, the curve can be scaled (`A' = 2260.7` for three
full S in `6A`), or the sheet can simply be left automatic and allowed to grow.
The 3125 module does not depend on either choice.

Because `3125 = 25 * 125`, any whole number of `A` is already a multiple of 125,
and gaps of `A/5 = 625` stay on the grid. The grid does not force 5257 or any
prime; it is a drawing aid.

## Using it in a renderer

1. Build one half in local coordinates from the table (or evaluate the formulas
   directly at any `u`).
2. Place the inflection at the origin with tangent along `+x`; the outgoing half
   is the table. The incoming half is `(-x, -y)` of the same points.
3. Round on output, never before geometry decisions. A 0.5-unit shift in a
   control point is invisible; accumulating rounded positions is not.
4. If a cubic path is required, fit the points with the existing measured fitter
   (`clothoid_lab.bezier`); do not hand-place Bézier handles from the table.
